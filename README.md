# HandyToolkit Online

Free browser-based utility hub for JSON formatting, QR generation, password generation, Base64, UUID, hash, color, and JWT tools.

## Stack

- Next.js 15 App Router
- TypeScript
- Tailwind CSS
- next-intl
- Browser-only tool execution where possible
- GA4 `G-G0YE8ZCN66`

## User Experience Policy

- No popup, redirect, social bar, anchor, or third-party display network scripts.
- Tool inputs, outputs, copy buttons, and downloads must remain directly accessible.
- External links must be user-initiated and must not replace tool functionality.

## Development

```bash
npm install
npm run build
```

## Reports

Operational changes are logged under `reports/`.
